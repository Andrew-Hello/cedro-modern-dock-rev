# Stable Baseline: Cedro Modern Dock Rev v1.0.0

Frozen on 2026-08-26 after successful real-machine validation of the Rev feature set.

This branch is intentionally preserved as a known-good rollback point. Future feature development continues on `cedro-enhanced-window`.

Validated feature groups include:

- transparent top-level Dock composition
- optional always-on-top with fullscreen suppression
- four-edge magnetic docking and auto-hide
- Windows taskbar-aware bottom docking
- visible edge tail
- configurable Dock vertical padding
- independent running-indicator, hover-magnification, hover-label and window-preview switches
- unpinned running-app section
- right-click and drag-to-pin for running apps
- packaged Windows App/UWP pinning and relaunch via AUMID / AppsFolder
- Edge/Chromium installed web-app identity pinning
- configuration export/import, safety backup and automatic restart

Release tag: `rev-v1.0.0`
